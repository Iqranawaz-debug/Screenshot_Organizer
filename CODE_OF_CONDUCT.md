# Code of Conduct

## Our Commitment

Smart Screenshot Organizer welcomes contributors of all
backgrounds and experience levels.

We are committed to maintaining a respectful, inclusive,
and collaborative open-source community.

## Expected Behavior

Contributors are expected to:

- Communicate respectfully and professionally.
- Welcome beginners and new contributors.
- Provide constructive feedback.
- Respect different opinions and experiences.
- Focus discussions on improving the project.
- Respect user privacy and data security.

## Unacceptable Behavior

The following behavior is not tolerated:

- Harassment, discrimination, or personal attacks.
- Insulting or threatening comments.
- Sharing someone else's private information.
- Deliberately disruptive behavior.
- Malicious code contributions.
- Repeatedly ignoring community guidelines.

## Maintainer Responsibilities

The project maintainer may review, edit, hide, or remove
inappropriate contributions and restrict participation
when necessary.

## Reporting Problems

If you experience or witness harassment, discrimination,
or other unacceptable behavior, please report it privately.

**Community Contact:** screenshotorganizers.support@gmail.com

When reporting an incident, please include:

- A description of what happened.
- Relevant GitHub issue or pull request links.
- Any supporting information you are comfortable sharing.

Reports will be reviewed by the project maintainer.
Information will be handled discreetly, although absolute
confidentiality cannot be guaranteed.

Please do not report sensitive incidents through public
GitHub issues.

For ordinary bugs and feature requests, use GitHub Issues.
